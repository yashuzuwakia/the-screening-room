# The Screening Room — frontend

React + Vite UI. Entry: `src/main.jsx`.

- **Start:** from repo root `npm start`, or here `npm start`
- **Env:** `.env.local` from `.env.example`
- **API:** `VITE_USE_API=true` → calls `/api` (proxied to backend in dev)

See [ARCHITECTURE.md](../ARCHITECTURE.md) for what belongs in frontend vs backend.
